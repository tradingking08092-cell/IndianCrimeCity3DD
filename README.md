# Indian Crime City 3D — Prototype
Godot 4.3, mobile-oriented 3D open city prototype. Primitive buildings and car, walk, jump, enter/exit and drive.

## Controls
Android: drag lower-left to walk or steer; drag right side to rotate camera; JUMP and DRIVE buttons. Desktop: arrow keys, right-mouse drag, E, Space.

## APK
Upload the **contents** of this folder to GitHub including hidden `.github/workflows/android.yml`, then Actions > Build Android APK > Run workflow. Download artifact after success. Requires Godot 4.3 export templates and Android SDK. The workflow is a starting configuration and has not been verified on GitHub runners.

## Scope
This is a prototype with generated primitive 3D shapes, not photorealistic GTA 5 graphics. Better visuals need licensed meshes, textures, LOD, lighting and mobile performance testing.
